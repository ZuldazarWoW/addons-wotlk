# How to Install
1. Copy all the folders below.
2. Go to your World of Warcraft Folder (usually **C:\\world of warcraft\\**)
3. Navigate to **Interface\\AddOns** Folder
4. Paste the folders previously copied.
5. Open World of Warcraft.
6. Click on Addons Button at Left Bottom Corner.
7. Enable the Addon that you had downloaded.
8. Join in Azeroth and Enjoy!
